# Security Policy

The 5G SBA Attack & Defence Lab is strictly for safe, offline simulation. The project does not
interact with real carrier networks or RF environments.

## Reporting a vulnerability
- Email: security@example.com
- Please include reproduction steps, affected components, and potential impact.
- Do **not** publicly disclose until maintainers have acknowledged and triaged the report.

## Scope
- Simulation code, configuration files, and documentation in this repository.
- Container and API configurations used by the lab.

## Out of scope
- Real-world network exploitation, RF manipulation, and any activity outside the lab network.

## Supported versions
Security fixes target the main branch. Contributors should base patches on the latest codebase.
